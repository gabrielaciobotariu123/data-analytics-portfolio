# Sales Data Cleaning and Performance Dashboard

## Project overview

This project uses Google Sheets to clean, validate and analyze a
sales dataset containing orders, customers, products and salespersons.

The analysis covers revenue, profit, order volume, customer performance,
product performance, locations and payment methods.

## Tools and techniques

- Google Sheets
- Pivot tables
- VLOOKUP
- IF and IFERROR
- COUNTIF
- Data validation
- Data cleaning
- KPI calculation
- Charts and dashboards

## Data cleaning

The source data contained:

- duplicate order identifiers
- inconsistent customer names
- inconsistent city and category names
- missing payment methods
- negative and zero quantities
- negative product prices
- inconsistent date formats

I created validation and cleaned columns to identify and standardize
these issues while preserving the original data.

## Dashboard

The dashboard includes:

- total revenue
- total profit
- total valid orders
- profit margin
- monthly revenue and profit
- revenue by city
- revenue by product
- top customers by revenue
- orders by payment method

## Key results

- Total revenue: 821,855 RON
- Total profit: 245,636 RON
- Valid orders analyzed: 43
- Overall profit margin: 29.9%
- Bucharest generated the highest revenue
- Laptop Lenovo generated the highest product revenue
